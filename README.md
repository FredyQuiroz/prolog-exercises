# Ejercicios de Prolog / Prolog exercises

[Español](#español) · [English](#english)

## Español

Ejercicios para aprender a responder preguntas con hechos y reglas. Utilizan relaciones familiares ficticias y relaciones geográficas como ejemplos.

### Qué puedes hacer

- Consulta hechos y relaciones de parentesco en `familia.pl`.
- Explora relaciones geográficas en `mapa.pl`.
- Compara un hecho explícito con una respuesta deducida por una regla.

### Ejemplo

Abre `familia.pl` y elige dos personas ficticias que aparezcan en los hechos. Comprueba qué relaciones se pueden inferir.

### Cómo empezar

Carga el archivo `.pl` del ejercicio en un intérprete Prolog compatible. Consulta los hechos y predicados definidos allí.

Puntos de entrada en el código. [`familia.pl`](familia.pl), [`mapa.pl`](mapa.pl).

Las fechas del historial se apoyan en Git o en la evidencia disponible de los respaldos. Las fechas reconstruidas a partir de archivos sin zona horaria usan las 12:00 UTC como referencia.

## English

Exercises for learning to answer questions from facts and rules. They use fictional family relationships and geographic relationships as examples.

### What you can do

- Query family facts and relationships in `familia.pl`.
- Explore geographic relationships in `mapa.pl`.
- Compare an explicit fact with an answer inferred by a rule.

### Example

Open `familia.pl` and choose two fictional people listed in the facts. See which relationships can be inferred.

### Getting started

Load the exercise’s `.pl` file into a compatible Prolog interpreter. Query the facts and predicates defined there.

Entry points in the source. [`familia.pl`](familia.pl), [`mapa.pl`](mapa.pl).

History dates come from Git or available backup evidence. Reconstructed dates from files with no time zone use 12:00 UTC as a reference.
